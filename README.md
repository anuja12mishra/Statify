# Statify

![Statify Logo](client/src/assets/logo-dark.png)

**Statify** is a modern, feature-rich task and status management application designed to boost productivity and keep your life organized. With a sleek, intuitive interface and powerful backend integration, Statify helps you manage your time and tasks effectively.

## Features

-   **Task Management**: Create, edit, delete, and manage your daily tasks.
-   **Status Tracking**: Track the status of your tasks (Completed, Pending, etc.).
-   **Dashboard Analytics**: Visualize your productivity with insightful charts and graphs.
-   **Responsive Design**: Beautiful UI that works seamlessly on desktop, tablet, and mobile devices.
-   **Dark Mode**: A stunning dark theme for comfortable late-night work sessions.

## Tech Stack

-   **Frontend**: React, Vite
-   **Styling**: Tailwind CSS
-   **HTTP Client**: Axios
-   **Routing**: React Router DOM
-   **Notifications**: React Toastify

## Prerequisites

-   [Node.js](https://nodejs.org/) (v18 or higher recommended)
-   [npm](https://www.npmjs.com/) (usually comes with Node.js)

## Getting Started

### 1. Clone the Repository

```bash
git clone <repository-url>
cd Statify
```

### 2. Backend Setup

Follow the instructions in the `server` directory to set up the backend API and database.

### 3. Install Dependencies

Navigate to the client directory and install the frontend dependencies:

```bash
cd client
npm install
```

### 4. Run the Application

Start the development server:

```bash
npm run dev
```

The application will be available at [http://localhost:5173](http://localhost:5173).

## Development

To create a production build:

```bash
npm run build
```
